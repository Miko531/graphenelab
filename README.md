# GrapheneLab

GrapheneLab — статична браузерна лабораторія для дослідження графену, графенових польових транзисторів, радіаційних сенсорів і шумів.

## Запуск

```powershell
python -m http.server 8080
```

Відкрийте `http://localhost:8080/`. Збірка не потрібна. Графіки Chart.js завантажуються з CDN, а фізичні модулі залишаються локальними ES-модулями.

## Можливості

- Багатошарова архітектура сенсора: інкапсуляція, графен 1–5 шарів, h-BN, SiO₂, Al₂O₃, SiC або підвішений графен.
- Живі Canvas-візуалізації взаємодії радіації, шумів, зонної діаграми та радіаційного імпульсу.
- SRIM / TRIM-подібний калькулятор: гальмівна здатність, пробіг, розкид, вакансії, DPA, каскади та розподіл іонів.
- Seeded-шум, FFT, спектральна густина потужності, статистика, локальне збереження експериментів і CSV-експорт.
- Єдина панель детектування частинок у GFET із сирим/відфільтрованим сигналом, трьома синхронними графіками та порівнянням СНР до і після DSP.

SRIM і радіаційні моделі є оцінковими феноменологічними моделями. Для проєктування реальних детекторів їх потрібно калібрувати за експериментальними даними.
